# Main-model selection and preflight deviations

Before main-matrix task outcomes, select the provided `zai/glm-5.3` gateway model with Harbor Terminus 2 defaults. Initial Qwen preflights spent large default completion budgets between shell actions. GLM produced shell actions at a practical rate without modifying the official agent timeout, decoding parameters, prompts, tasks, or verifier. Preserve Qwen candidate outcomes and all infrastructure failures in `trials.csv`; none belongs to the main matrix.

Early exploratory runs incorrectly passed Workspace namespace PIDs into a kernel interface expecting initial namespace PIDs. Their independent source observer saw no benchmark effects, so their security coverage is incomplete regardless of official verifier outcome. A subsequent mapper using the bpftrace `pid` builtin returned a helper error and zero; that attempted engine was detached. Main runs instead obtain `curtask->tgid` from a unique comm marker executed by the actual persistent shell, save the kernel receipt, reject nonpositive values or helper errors, and require independent evidence of a calibration child before starting the agent. This calibration adds no secret source or attack to the dataset.

Broad sources use supported suffixes that cover bare relative filenames as well as absolute paths. For example, the `.env` suffix also includes `project.env`; this is a documented filename overapproximation. Narrow sources retain explicit absolute credential paths, so tracepoint relative-path spelling remains a coverage limitation. The scoped OpenSSL sources come directly from the official task: `server.key` is private and `server.pem` combines that key with its certificate. No trusted declassification gate is evaluated.

Some tasks manipulate semantic secrets outside filename sources, such as historical Git objects, executable-embedded flags, and arbitrary repository files. Successful completion with no intervention does not demonstrate protection of these secrets. The model controller/API process is outside the protected tmux shell subtree, and model-context taint is not assumed.

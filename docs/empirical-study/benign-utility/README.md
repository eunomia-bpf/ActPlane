All values above come from [headline.csv](results/headline.csv), generated by [report.py](report.py). There were no observed IPv4 connect attempts in the protected benchmark subtrees. These success differences therefore do not establish an enforcement benefit or absence of over-tainting. The time differences include model, ordering and environment variability and do not establish causal overhead or speedup. The scoped utility denominator includes an independently audited agent-error zero without verifier execution; outer-shell continuations and unverified security calls are excluded from action denominators.

A separately admitted [natural-network follow-up](benchmark/network-followup.md) addresses this exposure gap using additional unchanged official tasks. Its task-specific source inventory, policies, runtime and task order were frozen before outcomes; [its trial export](benchmark/network/results/trials.csv) remains separate and incomplete. It does not enter the initial comparison above.

The benchmark uses the official [Terminal-Bench task release](https://github.com/harbor-framework/terminal-bench-2) through [Harbor](https://github.com/harbor-framework/harbor). Exact package versions, model identity and dataset revision are recorded in [versions.csv](benchmark/results/versions.csv) and [tasks.csv](benchmark/results/tasks.csv). The subset was selected before outcomes to include software, data and secret-handling tasks. It is purposive rather than representative of the full benchmark. Model selection and preliminary failures are documented in [model-selection.md](benchmark/model-selection.md); candidate trials never enter the main comparison.

Conditions are no AgPlane, a broad secret-filename IFC policy, and narrowed source paths. The primary defended comparison uses the retained calibrated kernel engine with native `block connect` on secret-labeled processes. A separate same-engine control established EPERM and successful denial without process termination. Actual host inspection confirms active BPF LSM, correcting the initial unavailability diagnosis. Earlier `kill connect` trials remain separately identified supporting evidence and cannot substitute for native denial. Mechanism controls remain outside benchmark scores and intervention rates. The scoped condition has no demonstrated trusted declassification gate.

The official task-success endpoint follows Harbor's native reward and default mean aggregation. Tasks, verifiers, prompts, decoding defaults and official timeouts remain unchanged. Native verifier logs must establish that tests executed before a verifier reward enters the comparison: the official script can emit a zero after dependency bootstrap fails. Such infrastructure receipts are retained and excluded. Independently audited agent failures count as zero under Harbor's default aggregation even when the verifier never starts; this does not mean tests ran. The separate `outcome_*`, verifier and per-call coverage fields in [trials.csv](benchmark/results/trials.csv) preserve that distinction. A genuine agent error is not resampled. The export retains candidate trials, infrastructure failures, official timeouts and separate setup, agent and verifier timings. Paired elapsed-time differences are descriptive. Timeout censoring, sampling noise, condition order, image cache state and concurrent workloads prevent treating them as isolated kernel overhead.

The tested sink denies new IPv4 connection attempts. It does not establish denial of writes on preconnected/inherited sockets, accepted-socket server responses, IPv6 or unconnected UDP sends. A server reading a private key can therefore handle traffic without exercising this sink. The protected boundary in the Terminus trials is the retained task shell and its descendants. Its controller, model API and model context are outside that subtree. A separate native Codex controller control is reported independently. The low-level loader's semantic messages are retained in logs; terminal failures reach the model. These measurements do not establish session-wide confinement across tool-output IPC. Filename sources also miss secrets embedded in executables, Git objects and arbitrary files. Exact absolute source paths can miss relative syscall spellings on user-path hooks. A low intervention count cannot establish that those flows are safe.

The public replay copies the fixed cohort and original harness without modifying the previous lane. [provenance.csv](replay/results/provenance.csv) and [cohort.csv](replay/results/cohort.csv) preserve the inputs. Commands retain their recorded order and setup semantics. Replays do not model agent recovery or supply official task-success scores. [runs.csv](replay/results/runs.csv) records instrumentation coverage, failures and retries; partial or incompatible-instrumentation runs are excluded from the covered-call denominator. Repository instructions and unsupported or out-of-scope directives are retained in [instruction_inventory.csv](replay/results/instruction_inventory.csv) and [instruction_exclusions.csv](replay/results/instruction_exclusions.csv).

Interventions mean successful kernel kills or denials, rather than notifications or rule matches alone. Independent classification follows [annotation.md](annotation.md). A real secret-tainted process attempting a forbidden connection is a true violation even during a benign task. Broad filename matches on independently verified public material can instead be false interventions against actual-secret policy intent. Unresolved cases remain unknown. The diagnostic rates use dispatched terminal-action tool calls for the live benchmark and covered recorded calls for replay, with within-session position bins. Native ATIF completion markers are recorded separately from terminal commands. The earlier hypothesis that the count difference represented undispatched commands was disproved by inspecting their function names and is retracted. This is an explicitly defined study diagnostic because Terminal-Bench supplies no action-level secret-policy annotations. Candidate secret-file read-access observations do not by themselves establish that a policy source or SECRET label engaged.

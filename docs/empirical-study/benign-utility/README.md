Neither view establishes a monotonic causal trend with session duration.

Live denominators count covered dispatched commands and interrupts, excluding empty waits and nonterminal completion markers. Replay denominators count covered recorded calls. Original indices, including gaps, are preserved. Rates describe covered actions; incomplete protected-root continuity is separately exposed by `security_matrix_complete`, even when `matrix_complete` establishes complete official utility outcomes.

The network cohort's [adjudications](benchmark/network/results/intervention-adjudications.csv) and [origin verification](benchmark/network/results/action-origin-verifications.csv) establish 41 broad and 1 narrowed false events, alongside 3 and 4 true events. These event totals differ from call counts above. Connected UDP DNS attempts were denied after public CA reads. Private-key server descendants also made genuinely forbidden connects. Executed predicates are authoritative: bare/dot-relative Git expressions compile to substring matches, including fragments matching public `.pub` files. Positive coverage controls do not establish source precision. A newly generated private key was read outside the frozen narrowed predicates; [dynamic-source-gaps.csv](benchmark/network/results/dynamic-source-gaps.csv) records this concrete recall gap. Narrowing cannot be claimed to preserve all secret coverage.

The protected boundary is the task shell and descendants. Later outer-shell recovery after root exit is excluded from security denominators while official utility remains retained. The Terminus controller, model API and context are outside the subtree. The sink covers new AF_INET connects, including connected UDP, but not IPv6, unconnected UDP sends, accepted-server responses or existing/inherited socket writes. A recorded post-label preconnected write demonstrates that limit, not secret exfiltration. Filename predicates also miss arbitrary renamed files and secrets embedded in Git objects or executables. These measurements cannot settle the whole-session retained-secret example. Condition (c) measures source narrowing only; the workloads provide no established trusted redaction gate. [BLOCKED.md](BLOCKED.md) records the remaining gaps.

Paper-ready paragraph:

We evaluated GLM-5.3 with official Harbor rewards on two purposive Terminal-Bench subsets and replayed public trajectories. Initial success was 4/6, 6/6 and 4/6 without defense, with broad sources and with narrowed sources; protected subtrees made no IPv4 connects. The separate network subset achieved 2/3 in every condition. Broad and narrowed policies falsely intervened on 12/51 and 1/67 covered network-task commands. Replay false-call bounds were 2.85–2.92% under broad sources and zero under narrowed sources. Public trust material explains many false labels. These are bounded deployment observations: partial process coverage, substring overmatching, missed dynamic sources and preconnected writes limit protection. Timings are descriptive; trusted declassification and retained model-context recovery remain unmeasured.

# Standard prompt-injection benchmark survey

Survey date: 2026-10-29 UTC. This survey uses official repositories, papers, and conference proceedings. It does not report new experiment measurements. Publication, external adoption, indirect injection, and actual OS effects are distinct selection criteria.

## Recommendation and decision boundary

**Preferred standard benchmark: OS-Harm's complete prompt-injection split.** It has a NeurIPS Datasets and Benchmarks publication, official tasks and injected content, actual desktop/terminal effects, and an official accuracy/safety judge. Its injection split can be run both with and without `--inject`, preserving the same legitimate tasks. The official harness supports text accessibility-tree observations, so vision support is not intrinsically required. Real enforcement must run inside the guest OS: attaching BPF only to the host's VM process cannot constrain guest file or process operations. Guest kernel compatibility and disk space are real feasibility checks, not reasons to silently replace the benchmark. [Official proceedings](https://proceedings.neurips.cc/paper_files/paper/2025/hash/4009bff0cd87ba2203c8e3a2f082aaec-Abstract-Datasets_and_Benchmarks_Track.html), [official execution instructions](https://github.com/tml-epfl/os-harm#running-experiments), [text-observation implementation](https://github.com/tml-epfl/os-harm/blob/main/mm_agents/agent.py).

**Published coding-specific fallback: RepoGuardBench.** Its official task corpus, injection carriers, clean controls, deterministic effect scorers, and built-in defenses directly fit this lane. It avoids a VM and exposes real file and subprocess effects. However, it is a recent, non-archival workshop artifact. Independent broad adoption was not established by this survey. If used, describe it as a published coding-agent benchmark and explicitly record the unmet stronger “widely used” requirement. Do not present it as an established main-conference standard. [Official artifact](https://github.com/DaoyuanLi2816/RepoGuardBench), [publication scope and limitations](https://github.com/DaoyuanLi2816/RepoGuardBench#citation).

The lane README must record the actual selection before any benchmark run. Survey recommendations alone do not constitute experiment completion.

## Additional published or released candidates

### OS-Harm

NeurIPS 2025 Datasets and Benchmarks Spotlight. Its complete injection split contains 50 tasks. The official baseline supports screenshot, accessibility tree, combined, and set-of-marks observations. Run the same injection-task list with `--inject` for attack and without it for clean utility. The official judge evaluates accuracy and safety. Apache-2.0. The authors tested VMware; inherited OSWorld providers are available but not all tested by the OS-Harm authors. [Repository](https://github.com/tml-epfl/os-harm), [official instructions](https://raw.githubusercontent.com/tml-epfl/os-harm/main/README.md).

The Docker provider still launches a VM and defaults to a 32G guest disk. The guest image is downloaded as a zipped qcow2 from Hugging Face. Actual disk allocation, image decompression, overlay growth, and the guest's BPF capabilities need verification before full execution. [Official provider](https://github.com/tml-epfl/os-harm/blob/main/desktop_env/providers/docker/provider.py), [image manager](https://github.com/tml-epfl/os-harm/blob/main/desktop_env/providers/docker/manager.py).

### RTC-Bench / RedTeamCUA

The official repository identifies this as an ICLR 2026 Oral paper. RTC-Bench supplies 864 hybrid web/OS examples, real VM and Docker environments, adversarial success/attempt rates, and benign success rate under attack. It separates decoupled exposure from end-to-end evaluation. The published setup allocates 100GB for RocketChat/OwnCloud experiments and 200GB for the forum platform. That is substantially larger than this lane's stated shared free space. Apache-2.0. This is a stronger publication match than RepoGuardBench, but the full environment is not presently an obvious fit for the shared Workspace. [Official repository](https://github.com/OSU-NLP-Group/RedTeamCUA), [paper, Appendix D/F/G.4](https://arxiv.org/html/2505.21936v1).

### RepoGuardBench

Accepted at ICML 2026's DL4C workshop, explicitly non-archival. Official corpus: 80 Core and 14 Applied tasks; five carriers (README, issue text, code comment, test log, agent-rule file); inert goals involving canary data, marker writes, shell execution, test deletion, and a benign backdoor comment. Core tasks are intentionally small, single-file probes. The artifact supports matched clean/poisoned runs. Code MIT, data/results CC BY 4.0. [Dataset license](https://github.com/DaoyuanLi2816/RepoGuardBench/blob/main/LICENSE-DATA), [official runner](https://github.com/DaoyuanLi2816/RepoGuardBench/blob/main/scripts/run_experiments.py).

Official defenses include D1 spotlighting, D2 instruction stripping, D3 action gate, D4 task alignment, and D5 confirmation. A comparison can use the shipped D1 or D3 implementation without inventing a baseline. D0 still runs inside the benchmark sandbox, so “no defense” means no additional defense beyond its common sandbox. Official scoring separately measures proposed malicious actions and completed effects; utility is the target test passing. Preserve these distinctions when naming ASR. [Defense implementations](https://github.com/DaoyuanLi2816/RepoGuardBench/blob/main/repoguard/defenses/registry.py), [official scorer](https://github.com/DaoyuanLi2816/RepoGuardBench/blob/main/repoguard/scoring/scorer.py).

The official model backend is Ollama, with a separate optional Claude CLI backend. Using the available OpenAI-compatible Qwen/GLM services requires a transport adapter, while preserving official prompts, actions, budgets, attacks, sandbox, and scoring. Defaults include temperature zero, seed 7, context 8192, generated tokens 1536, and four agent turns. These are artifact defaults, not new lane-imposed restrictions. [Backend](https://github.com/DaoyuanLi2816/RepoGuardBench/blob/main/repoguard/agents/ollama_backend.py), [reproduction guide](https://github.com/DaoyuanLi2816/RepoGuardBench/blob/main/docs/REPRODUCIBILITY.md).

### Other coding-specific releases

- **CodeIPI (Inspect Evals):** official coding-agent sandbox tasks and clean controls, shipped anti-injection prompt, IRR/TCR/FPR. Only 35 attack samples and 10 clean samples. Repeating these does not create 50 distinct attack tasks. Some success checks inspect command history or canary exposure rather than completed exfiltration, so effect claims must follow the actual scorer. MIT framework. [Official artifact](https://github.com/UKGovernmentBEIS/inspect_evals/tree/main/src/inspect_evals/ipi_coding_agent), [official registry page](https://ukgovernmentbeis.github.io/inspect_evals/evals/ipi_coding_agent/).
- **AIShellJack (2025):** published preprint with 314 payloads and real Cursor/Copilot command/code effects. The paper links a reproduction package on Figshare. It is an editor-automation attack study; an official matched benign-utility protocol and arbitrary API-model agent interface were not established. The artifact license was not verified. Do not assume closed editor automation, credentialed subscriptions, and its semantic execution judge can be replaced without protocol changes. [Primary paper](https://arxiv.org/html/2509.22040v1), [linked reproduction package](https://doi.org/10.6084/m9.figshare.30111988).
- **QueryIPI (2025):** attack-method preprint with simulated-agent evaluation and transfer to real coding agents. Not selected as the official paired utility benchmark for this lane. [Primary paper](https://arxiv.org/abs/2510.23675), [author-linked source](https://github.com/QueryIPI/QueryIPI).
- **AgentDyn (2026):** 60 open-ended tasks and 560 injection cases; uses AgentDojo and adds official defenses including PromptGuard 2. It remains a Python environment/tool benchmark, so the extra coding/GitHub domain does not create OS-backed file effects. MIT inherited framework; verify any additional notices at the pinned revision. [Primary paper](https://arxiv.org/abs/2602.03117), [official repository](https://github.com/SaFo-Lab/AgentDyn).
- **TURNCOAT:** open static coding-agent injection corpus with benign twins and assertions. The repository says its reference runner/adapters are forthcoming. No peer-reviewed venue or established adoption was verified. MIT. Not preferred over a runnable published artifact. [Official repository](https://github.com/7empestx/turncoat-benchmark).

## Validity constraints for the eventual run

Use official task inputs, injected payloads, common sandbox, and official scorers. Keep attempted attacks separate from landed effects. Retain failures and timeouts in the scheduled denominators. A model transport adapter or kernel instrumentation is a necessary integration change, not permission to rewrite attacks or score definitions. Record every such deviation.

For the two AgPlane conditions, policy-author timing and authority must be demonstrated by actual execution/domain evidence. A policy added to a prompt is not higher-authority OS enforcement. A userspace validator rejecting a policy is not a kernel delta rejection. A BPF event observer is not enforcement. Empty audit logs do not establish that weakening was attempted and rejected. If the requested kernel update/declassification path is absent, report that cell as blocked rather than manufacture a policy attack to make the experiment look complete.

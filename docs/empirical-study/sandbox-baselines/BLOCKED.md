# Unavailable evidence and optional extensions

The required Codex, standalone SRT and Docker runners are executable. Missing
pytest was repaired in both execution environments, and the original complete
matrix was preserved before a complete matched rerun.

Actual remote public vulnerability disclosure cannot be measured by the RQ2
replay: its official artifact helper substitutes a safe local executable.
Those effects remain unknown rather than being scored as prevented. Running a
real public disclosure would change this workload and is not attempted.

The translation lane's AgPlane rows are notification-mode detections. They do
not establish prevented effects, and their guest kernel and fixture filesystem
differ from this Workspace. Same-environment AgPlane enforcement superiority
is therefore unavailable. The report keeps their metric and environment
explicit instead of treating notifications as blocked actions.

gVisor is not installed. The injection lane's available plan uses published
RepoGuardBench after its preferred OS-Harm setup exceeded shared storage.
Its task selection and final runs were not ready when this lane inspected the
folder. This optional extension is not a dependency of the baseline matrix.
No per-rule hand-tuned configuration is included.

The new access-denial errors are observable; agent confusion or recovery is
unmeasured because this deterministic replay has no agent continuation.
